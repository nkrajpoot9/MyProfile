# Security Policy

## Supported Versions

This project is a static personal portfolio website, so it does not use a formal software release cycle. The latest version on the `main` branch is the only version actively maintained.

| Version | Supported | Notes |
| ------- | --------- | ----- |
| `main` / latest website | ✅ | Active maintenance and security updates |
| Archived or historical snapshots | ❌ | No security support after archival |
| Local or unpublished copies | ❌ | Not maintained by this repository |

## Reporting a Vulnerability

Please report security issues privately and responsibly. Do not disclose vulnerabilities publicly through issues, pull requests, or comments before they have been assessed and resolved.

To report a vulnerability, contact the maintainer at:

- Email: naveen.rajpoot@outlook.com

Please include the following in your report:

- A clear description of the vulnerability
- Steps to reproduce the issue or proof of concept
- Affected page, file, or URL, if applicable
- Estimated impact and severity
- Any suggested remediation steps

Response expectations:

- Initial acknowledgment within 5 business days
- Regular updates during investigation and remediation
- Clear communication on whether the issue is accepted, declined, or requires additional information

If a vulnerability is confirmed, we will work to fix it promptly and coordinate a responsible disclosure timeline where appropriate.
